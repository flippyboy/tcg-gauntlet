# 2015 Modern example gauntlet

This gauntlet is an example. It uses the `preset:2015-modern@1` format: the core sets and expansions from Eighth Edition to Magic Origins, with the Modern banned list of January 2015.

Replace it with your own gauntlet, or delete this folder.

Each `.txt` file in this folder is a deck. A `.md` file with the same name is that deck's primer.
